# materials/

Offline reference for the month away from the camera and (sometimes) the internet.
Everything here is a snapshot from **2026-09-09**; verify library APIs against the installed
version when in doubt.

Not a duplicate of the repo root — `PLAN.md`, `TIMELINE.md`, `BIBLIOGRAPHY.md`,
`RECORDING_LOG.md` live there and stay authoritative. This tree is background you can read
without a network.

| Dir | What's in it |
|---|---|
| `00-project/` | The CFP text, the decisions made this session and why, the scope boundary. |
| `01-literature/` | Detailed notes on the papers — enough to write related-work offline. |
| `02-methods/` | Equations and setup for every method in play: reservoir/FORCE, LMU, periodic Kalman, rhythmic DMP, event representations, metrics, v2e simulation. |
| `03-tooling/` | Cheatsheets: reusing the thesis repo, snnTorch, Nengo/LMU, IEEE LaTeX, the Python env. |
| `04-checklists/` | Weekly cadence, paper submission. |

Suggested reading order on day one: `00-project/decisions-log.md` →
`01-literature/closest-prior-art.md` → `02-methods/reservoir-computing.md` →
`03-tooling/thesis-repo-reuse.md`.
