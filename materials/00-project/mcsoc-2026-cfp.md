## Format
- IEEE Conference Proceedings style (`\documentclass[conference]{IEEEtran}`), two-column.
- **8 pages including references** (supervisor's limit; CFP text itself doesn't state one).
- Paper categories: Regular, Short, Presentation-Only.
- Published in IEEE Xplore + IEEE CS Digital Library; indexed EI Compendex, Scopus, ISI.
- Standard IEEE peer review. Best Paper and Best Student Paper awards.
- Original technical, experimental, theoretical, conceptual, **or survey** papers accepted.

## Co-located summits this work maps onto
- **MCSoC-NeuroCore** — neuromorphic architectures, spiking neural networks, brain-inspired
  computing.
- **MCSoC-EmbodiCore** — embodied intelligence, sensorimotor integration, real-time edge
  systems for robotics and cyber-physical platforms.

## Technical areas (abridged, relevant ones)
- Neuromorphic and Brain-Inspired Architectures for Multicore SoCs — spiking neural networks,
  event-driven processing, asynchronous logic, **synaptic memory structures**, neuromorphic
  accelerators.
- Multicore SoCs for Cyber-Physical and Autonomous Systems — sensor fusion, control loops,
  real-time autonomy, edge intelligence.
- Hardware Acceleration of AI on Embedded Edge SoCs — inference engines, dataflow
  architectures, quantisation, HW/SW co-design for edge AI.
- Machine Learning for Energy-Efficient and Reliable Manycore Systems.
